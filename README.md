# 백층의 검 (1층 시험판)

2D 횡스크롤 액션. `index.html`을 브라우저(모바일은 가로 화면 권장)로 열면 바로 플레이할 수 있습니다.

- 목숨 3개 · 층마다 제한시간 3분 · 적을 모두 처치하면 클리어 (100층 예정, 현재 1층만)
- 제한시간 초과 또는 체력 소진 → 목숨 1개를 잃고 해당 층 재도전

## 조작
| 입력 | 동작 |
|---|---|
| 화면 터치 (PC: 클릭) | 터치한 위치로 고속 이동. 지면에서 공중을 찍으면 점프 |
| 공중에서 화면 터치 | **월보** — 허공을 박차 이동. 2회, 착지하면 회복 |
| (공중 이동 후) | 2초간 그 자리에 떠 있다가 낙하 (`HANG_TIME`) |
| **빨간 버튼** 누르고 있기 (PC: Space/J) | 플레이어 외 전부 슬로모션 (게이지 소모, 떼면 회복) |
| 적 공격 순간 빨간 버튼 | **패링** → 적이 무너져 온몸이 약점 |
| 급소(뒤통수 ◆) 근처에서 빨간 버튼 | 급소 공격 시작 |
| 공격 중 빨간 버튼 연타 | 딜 (공격 중엔 자동 슬로모션) |
| 공격 중 화면 터치 | 공격 중단 후 그쪽으로 도주 |

적의 반격 직전에는 화면 가장자리가 붉게 깜빡입니다.

## 밸런스 값
`index.html` 상단 상수 블록(`SLOW`, `PARRY_PRE`, `GRAB_COUNTER`, `ENEMY_TYPES` 등)과 `buildFloor(n)`에서 조정합니다.
