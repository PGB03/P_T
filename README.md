# 백층의 검 (1층 체험판)

2D 횡스크롤 리듬 액션. `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.

- 목숨 3개, 층마다 제한시간 3분, 적을 모두 처치하면 클리어
- **전진 / 후진** (D·→ / A·←): 길게 눌러 이동
- **패링** (K / Space): 적 머리 위 링이 노랗게(“지금!”) 변할 때 → 적 **흐트러짐**(받는 피해 +50%)
- **공격** (J): 근접 시 리듬 연격 시작. 노트에 표시된 버튼을 판정원에 맞춰 누르면 n타째 데미지 ×n (최대 ×5). 놓치면 연격이 끊기고 적이 반격
- Esc / P: 일시정지
